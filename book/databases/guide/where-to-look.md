# Where to look for…

| Question | First choice | Also useful |
|---|---|---|
| Official symbol, aliases and identifiers of a gene | NCBI Gene (Summary) | HGNC, Ensembl (gene summary and External references) |
| Chromosomal location, strand, gene structure | Ensembl (gene page, Genome browser) | NCBI Gene (Genomic context) |
| How many transcripts, which code for protein | Ensembl (Transcripts table) | NCBI Gene (RefSeq section) |
| The reference transcript for reporting variants | MANE Select, in Ensembl or NCBI | |
| RefSeq identifiers (NM_, NP_, NG_) | NCBI Gene (RefSeq section) | dbSNP (Variant Details) |
| Orthologues in other species | Ensembl (Gene relationships, Homology) | NCBI Gene (General gene information, Homology) |
| In which tissues a gene is expressed | NCBI Gene (Expression) | Expression Atlas, Human Protein Atlas |
| Diseases linked to a gene, with inheritance | OMIM (Gene-Phenotype Relationships) | NCBI Gene (Phenotypes), UniProt (Disease & Variants) |
| Background on a genetic disease | OMIM (phenotype entry) | |
| Alleles at a variant position, and their effect on transcripts | dbSNP (Variant Details) | Ensembl variant page (Transcript consequences) |
| Allele frequencies in populations | dbSNP (Frequency) | Ensembl variant page, gnomAD |
| Is this allele pathogenic? Who says so? | ClinVar | dbSNP (Clinical Significance), with a check in ClinVar |
| Effect of your own list of variants | Ensembl VEP | |
| What a protein does, with evidence | UniProt (Function, GO annotations) | NCBI Gene (Summary) |
| Where a protein is in the cell | UniProt (Subcellular Location) | GO cellular component |
| Post-translational modifications, signal peptide | UniProt (PTM/Processing) | |
| Protein isoforms | UniProt (Sequence & Isoforms) | |
| Interaction partners | UniProt (Interaction) | IntAct, pathway diagrams |
| Protein structure | UniProt (Structure) | PDB, AlphaFold DB |
| Pathways a gene or compound takes part in | WikiPathways | NCBI Gene (Pathways from PubChem), Reactome |
| What a small molecule is, and its biological roles | ChEBI | PubChem |
| Pharmacology, toxicity, safety of a compound | PubChem | |
| Data the new Ensembl site no longer shows (gene variant table, phenotypes, BioMart) | Ensembl archive, jun2026.archive.ensembl.org | ClinVar, dbSNP |
